## Project Overview

A React Router (Framework Mode) wedding website built with React 19, TypeScript, Vite 8, and Tailwind CSS v4.

## Commands

```bash
npm run dev       # Start dev server with HMR at http://localhost:5173
npm run build     # Production build
npm run start     # Serve production build (runs build/server/index.js)
npm run typecheck # Generate route types, then run tsc
```

## Tech Stack & Conventions

- **React Router Framework Mode** (v8) — uses `app/routes.ts` for route config, route modules under `app/routes/`, route exports like `meta`, `loader`, `action`, `ErrorBoundary`. SSR is enabled.
- **Tailwind CSS v4** — configured via CSS `@import "tailwindcss"` and `@theme` blocks in `app/app.css`. There is **no** `tailwind.config.js`. Custom theme values go directly in the `@theme` block. Use existing `@theme`-defined tokens like `--font-sans` where possible.
- **TypeScript** — strict mode enabled. Uses `~/*` path alias for `./app/*` imports.
- **React 19** — functional components, hooks.

## Project Structure

```
app/
  root.tsx              # Root layout, HTML shell, ErrorBoundary
  routes.ts             # Route definitions (currently single index route)
  routes/home.tsx       # Home page route module
  app.css               # Global styles + Tailwind v4 theme config
  welcome/              # Starter template components (to be replaced)
public/
  favicon.ico
```

## Constraints

- **No images, no forms, no external APIs.** The site is a static informational wedding site.
- All links should use placeholder URLs (no real URLs).
- Add new routes in `app/routes.ts` and create route modules in `app/routes/`.
- Styling is mobile-first with Tailwind utility classes.

## Key Patterns

- Route modules follow React Router conventions: default export for the component, named exports for `meta`, `loader`, `action`, `ErrorBoundary` as needed.
- Type-safe route imports use `./+types/<name>` paths generated by `react-router typegen` (run `npm run typecheck` after adding routes to regenerate).
- The `@tailwindcss/vite` plugin handles Tailwind compilation — no separate PostCSS config needed.
